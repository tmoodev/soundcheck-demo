Overview

SoundCheck Financial is a secure, multi-tenant financial dashboard that connects to your clients' bank accounts via Plaid. It gives your team a real-time view of account balances and transactions across all connected institutions — all in one place.

Navigation

Nav Item What it does
Summary Balance overview and account list for all connected banks
Transactions Searchable, filterable transaction history with CSV export
Users Admin Manage portal users, roles, and MFA settings
Clients Admin Create and manage clients and their account groupings
Banks Admin Connect bank accounts via Plaid, sync transactions, refresh balances
Audit Admin Security event log — logins, MFA changes, exports, and more
Tip: Admin-only sections (Users, Clients, Banks, Audit) are only visible in the navigation if your account has the Admin role.

Summary Dashboard

/dashboard/

The Summary page gives an at-a-glance view of all connected account balances. Use the filters at the top to narrow the view to a specific client or account type.

KPI Tiles

Total Balance

Sum of current balances across all displayed accounts.

Total Available

Sum of available balances (excludes pending holds).

Total Pending

Sum of all pending (not yet posted) transactions.

Filters

CSV Export

Click the Export CSV button (available on desktop) to download all transactions matching your current filters as a spreadsheet-ready CSV file. The filename includes the selected date range (e.g., transactions_2025-01-01_2025-03-31.csv).

Note: CSV export is only available on desktop browsers. The export button is hidden on mobile devices. Very large exports may be subject to a row limit — narrow your date range if needed.

Managing Clients

Admin Only

/manage/clients/

Clients are the people or entities whose finances you are managing. Bank accounts are grouped under clients so you can filter the Summary and Transactions views by individual client.

Creating a Client

  1. 1Go to Clients in the navigation and click Create Client.
  2. 2Enter the client's name. Leave Active checked unless you want to hide the client from filters.
  3. 3Click Create. The client will now appear in dashboard filter dropdowns.

Mapping Bank Accounts to a Client

After connecting a bank (see Connecting Banks), you can associate its accounts with a client so they appear when that client is selected in filters.

  1. 1Open the client's edit page (Clients → Edit).
  2. 2In the Account Mappings section, click Add Account Mappings.
  3. 3Select the accounts to associate with this client and click Add Accounts.
Tip: When you connect a bank and select a client during the connection flow, accounts are mapped automatically — no manual mapping step needed.

Connecting Banks

Admin Only

/manage/banks/

Bank connections are made through Plaid, a secure bank connectivity service. SoundCheck Financial never stores your banking credentials — only an encrypted access token that Plaid issues after authentication.

Connecting a New Bank

  1. 1Go to Banks and click Connect New Bank.
  2. 2Select the client this bank connection belongs to.
  3. 3Click Connect Bank Account. A secure Plaid window will open.
  4. 4Search for and select your bank, then follow the on-screen authentication steps.
  5. 5Once complete, accounts and transactions are automatically imported and visible on the dashboard.

Managing Connected Banks

Each connected bank appears as a card on the Banks page showing its accounts, balances, and sync status.

Action Description
Sync Transactions Fetches new, modified, and removed transactions from the bank. The result shows a count of changes made.
Refresh Balances Pulls the latest balance snapshot for all accounts in this connection. Reload the page after to see updated values.
Note: Some banks require periodic re-authentication through Plaid. If a bank connection shows an Error status, the client may need to reconnect their bank.

Managing Users

Admin Only

/manage/users/

The Users page lets administrators create and manage portal accounts, assign roles, and control MFA settings.

Roles

Role Permissions
Admin Full access to all pages including Users, Clients, Banks, and Audit Log.
User Access to Summary and Transactions only. Cannot access admin pages.

Creating a User

  1. 1Click Create User on the Users page.
  2. 2Enter the user's email address, display name, and assign a role.
  3. 3Click Create. Share the temporary password with the user securely.
  4. 4The user will be prompted to set up MFA on first login.

MFA Management Actions

Action Description
Reset MFA Clears the user's MFA secret, recovery codes, and trusted devices. The user will be required to set up MFA again on next login.
Regen Recovery Codes Generates a fresh set of 10 recovery codes and invalidates the old ones. Use this if a user loses their backup codes.

Multi-Factor Authentication (MFA)

/auth/mfa/setup/

MFA is required for all users. After your first login, you will be directed to set up MFA before accessing the dashboard. MFA uses a time-based one-time password (TOTP) that you generate with an authenticator app.

Setting Up MFA

  1. 1Install an authenticator app such as Google Authenticator, Microsoft Authenticator, or Authy.
  2. 2Scan the QR code shown on the MFA Setup page with your authenticator app. If you can't scan, tap Can't scan? to reveal the manual entry key.
  3. 3Enter the 6-digit code from your authenticator app to confirm setup.
  4. 4Save your recovery codes in a secure location. Each code can only be used once and they are the only way to access your account if you lose your authenticator.

Trusted Devices

At the MFA verification step, check Remember this device for 7 days to skip MFA on that browser for a week. This is recommended only on personal, secure devices.

Recovery Codes

Recovery codes are 10 single-use backup codes given when MFA is first set up. Enter any one in place of your 6-digit TOTP code if your authenticator is unavailable. Once used, a code cannot be reused. An admin can generate a new set via Users → Regen Codes.

Locked out? Contact your administrator to reset your MFA. They can use the Reset MFA action on the Users page to clear your MFA so you can set it up again on next login.

Password Reset

/auth/password-reset/

If you have forgotten your password, you can request a reset link via email.

  1. 1On the login page, click Forgot password?
  2. 2Enter your email address and click Send Reset Link.
  3. 3Check your email for a message from noreply@soundcheckfinancial.com. The link expires after 1 hour.
  4. 4Click the link in the email and enter your new password. You will be redirected to login.
Tip: For security, the reset form shows the same confirmation message whether or not the email address exists in the system — this prevents account enumeration.
